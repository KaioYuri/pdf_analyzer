# **App Name**: PDF Analyzer & Summarizer

## Core Features:

- PDF Summarization: Analyze the entire PDF document and generate a concise, accurate summary using advanced NLP techniques.
- PDF Upload: Provide a clean and intuitive interface for uploading PDF documents.
- Summary Display: Display the summarized text in a readable format.
- Summary Export: Allow users to save the generated summaries as text files.

## Style Guidelines:

- Primary color: Neutral gray (#666666) for a professional look.
- Secondary color: Light gray (#EEEEEE) for backgrounds and spacing.
- Accent color: Teal (#008080) for interactive elements and highlights.
- Body font: 'Roboto' for readability and a modern feel.
- Headline font: 'Montserrat' for emphasis and visual appeal.
- Use simple, clear icons to represent actions like upload, save, and summarize.
- Maintain a clean, well-spaced layout with a focus on readability.
- Subtle loading animations and transitions to provide feedback during analysis and summarization.
